# The Game Boy ROM

Everything you see on the Game Boy screen is this ROM. It's written in C with
[GBDK-2020](https://github.com/gbdk-2020/gbdk-2020) and runs on an original DMG.

It never holds a key. It draws screens, reads buttons, and talks to the
cartridge's chip through a small mailbox in cartridge memory (see
[docs/protocol.md](../docs/protocol.md)). The chip answers; the ROM shows what
the chip says and asks you to confirm.

```sh
make          # build/wallet.gb, also copied to ../web/public/wallet.gb for the demo
make demo     # build/wallet-demo.gb, for a flash cart on a real Game Boy
make hw       # build/wallet-hw.gb, for the real cartridge: mailbox writes at 0xA000, reads at 0x7F00
```

`make hw` is what [hardware/sim](../hardware/sim) runs to simulate the cartridge.

The Makefile expects GBDK in `~/gbdk` (`make GBDK=/path/to/gbdk` otherwise).

| File | What it does |
|---|---|
| `src/main.c` | All the screens and the flow: setup, entropy, words, PIN, restore, home, receive, signing, pairing, the Phone menu |
| `src/gfx.c` | Text, boxes, icons and the big digits |
| `src/assets.c` | Tiles and fonts, generated by `assets/gen_assets.py` from the Pixel Operator font |
| `src/demo_chip.h` | The test chip's replies for `make demo`, generated by `assets/gen_demo_chip.mts` from the real chip code |
| `src/music_data.h` | The demo build's menu music, converted from a MIDI file by `assets/gen_music.py` |

## The flash-cart build

A flash cart has no key chip, so `make demo` compiles a test chip into the ROM
(`-DDEMO_CHIP`), with answers generated from the real chip code. It keeps the
wallet and PIN in the cartridge's battery RAM (MBC1 + RAM + battery) and wipes
after five wrong PINs like the real thing. It holds no real keys. It exists so
the whole flow can be held in your hands on a real Game Boy.

It also plays music on the menus: a MIDI arranged for the Game Boy's four
voices, with chords as fast arpeggios on the pulse channels, bass on the wave
channel and drums on noise. Menu, then Music, turns it off.

```sh
python3 assets/gen_music.py your-tune.mid   # needs `pip install mido`
make demo
```

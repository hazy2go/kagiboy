# kagiboy wallet cartridge: KiCad project

Status (2026-10-15): 6-layer 0.8 mm, placed, routed and tidied, all checks green. Not ordered yet
(`fab/ORDER.md`). Overview, checks and history: `../README.md` and `../LOGBOOK.md`.

Based on the [WiFi Game Boy Cartridge](https://github.com/hazy2go/wifi-game-boy-cartridge) Rev B board, which
documents where its own design comes from. Hardware licence: CERN Open Hardware Licence v2 Permissive
(`LICENSE-CERN-OHL-P.md`), inherited from that design.

What's here:
- `GameboyCartridgeV2.1.kicad_*`: the schematic (root, `cpu`, `power`, and `radio`, which holds the radio,
  power stage and wallet parts) and the board.
- `radio.kicad_sym`, `radio.pretty`: project symbols and footprints, generated by `tools/gen_radio_symbols.py`,
  `tools/gen_radio_footprints.py`, `tools/gen_wallet_footprints.py`. The added parts' sheet is generated from
  `../docs/design/netlist_radio.json` by `tools/gen_radio_sheet.py`.
- `fab/`: JLC order files.
- `art/`: the back-silkscreen logo source.
- `tools/`: placement, routing, clean-up, audits and fab tools. Each is documented at the top of the file.

Rules for changes:
- Change the design through `../docs/design/netlist_radio.json` and the tools, then run the checks in `../README.md`.
- Log every decision and result in `../LOGBOOK.md`.
